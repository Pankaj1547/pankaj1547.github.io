Privacy Policy

KidTube Studio · last updated 13 October 2026

KidTube Studio is a personal command-line tool. It runs on its author's own computer and publishes videos to its author's own YouTube channels. It has no users other than its author, no sign-up, and no server.

What data the application accesses

When the author signs in with their Google account, the application is granted access to that one account only, for these purposes:

  • Uploading videos (youtube.upload) — to publish videos the application rendered locally.
  • Managing those videos (youtube.force-ssl) — to set the title, description, tags, language, thumbnail and audience setting of videos on the author's own channels.
  • Reading performance figures (yt-analytics.readonly) — to read view counts, watch time and retention for those same videos, so the application can decide what to make next.

What is stored, and where

An OAuth token is stored in a single file on the author's own computer so the application does not have to ask for sign-in on every run. View and retention figures read from the Analytics API are stored in local files on the same computer.

No data is transmitted to any server operated by the author, because there is no such server. Nothing is uploaded anywhere except the videos themselves, which go to the author's own YouTube channels.

What is not done

  • No data is sold, rented, shared or disclosed to any third party.
  • No data is used for advertising or profiling.
  • No data is collected about viewers, subscribers or any other person. The Analytics figures read are aggregate counts for the author's own videos.
  • No other Google account is accessed. The application cannot read Gmail, Drive, Contacts or Calendar, and does not request those permissions.

Use of Google user data

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used solely to provide the function described above — publishing and managing the author's own videos — and for no other purpose.

Retention and deletion

The stored OAuth token can be revoked at any time from the account's Google Account permissions page, which immediately ends the application's access. Deleting the token file on the computer has the same practical effect locally. Locally stored analytics figures can be deleted by removing the application's state folder.

Children

The application is used only by its adult author. Some of the videos it publishes are children's content and are declared as such on YouTube, but the application collects no information from children or from any viewer.
